BUKU CATATAN KARTU STOK OBAT - PUSKESMAS NGALUPOLO

Aplikasi berada di folder buku-kartu-stok pada repositori kartu-stok-farmasi.

Cakupan lokasi:
Gudang Farmasi, Apotek, Poli dan Ruangan, Pustu 1, Pustu 2, Pustu 3, Poskesdes Reka, Poskesdes Wolokota, Poskesdes Kekasewa.

Fitur:
- Master obat dan satuan
- Saldo per obat per lokasi
- Penerimaan, pemakaian, kedaluwarsa/rusak
- Transfer masuk dan transfer keluar/penyaluran
- Edit dan hapus transaksi
- Kartu stok per obat dan lokasi
- Ringkasan stok dan pencarian
- Cetak/PDF, ekspor CSV, backup/pemulihan JSON
- Penyimpanan lokal dan cache offline PWA

Kebijakan saldo:
Saldo = penerimaan + transfer masuk - pemakaian - kedaluwarsa/rusak.
Transfer keluar hanya dicatat sebagai informasi penyaluran dan tidak mengurangi saldo otomatis.
Untuk memulai saldo awal, catat transaksi Penerimaan dengan keterangan "Saldo awal" pada masing-masing lokasi.

Data tersimpan di browser/perangkat. Belum ada sinkronisasi antar-HP. Cadangkan data secara berkala.
